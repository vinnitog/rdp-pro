# Avaliação de Anonimização — RDP Pro

**Data**: 2026-08-23
**Resultado**: não há pipeline de analytics, data warehouse, dataset público ou treinamento de modelo no repositório.

- Os insights são calculados no navegador sobre os registros do próprio titular.
- Remover apenas nome/e-mail não tornaria os registros terapêuticos anônimos; conteúdo e contexto podem permitir identificação.
- IDs internos continuam dados pessoais pseudonimizados quando existe vínculo reversível.
- Nenhum conjunto foi declarado anonimizado e nenhum teste de reidentificação se aplica ao estado atual.
- Se analytics ou pesquisa forem introduzidos, exigir supressão/generalização, k-anonymity mínimo 5, testes de singling-out/linkage/inference e documentação antes de declarar saída do escopo da LGPD (arts. 5º, XI, 12 e 13, §4º).
